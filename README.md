# Generative Modeling
Iteratively denoising my personal understanding of the high-dimensional, multi-modal world of Generative Modeling

## Setup & Installation

1. Clone the repository:
```bash
git clone git@github.com:vtechsavyy7/modeling_generation.git
```

2. Install UV package manager
```bash
curl -LsSf https://astral.sh/uv/install.sh | sh
```

3. Run UV sync to install dependencies & activate the virtual environment

```bash
uv sync
```
